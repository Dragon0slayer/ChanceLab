# ChanceLab 🎲

**ChanceLab** — навчальний застосунок на Flutter/Dart для вивчення та візуалізації основ теорії ймовірностей.

## Можливості

- Симуляція підкидання монети.
- Симуляція кидання кубиків.
- Візуалізація розподілів Бернуллі, біноміального та нормального.
- Калькулятор класичної ймовірності, протилежної події, об’єднання та перетину подій.
- Теоретичні матеріали та формули.

## Технології

- Flutter / Dart
- Material Design 3
- `flutter_math_fork` для математичних формул

## Запуск

1. Встановіть [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Відкрийте кореневу папку проєкту в терміналі.
3. Виконайте:

```bash
flutter pub get
flutter run
```

## Призначення

Курсовий навчальний проєкт для наочного дослідження випадкових подій та ймовірнісних розподілів.

> Вихідний код підготовлений до публікації; автоматичний запуск і тестування в цьому пакеті не проводилися.
